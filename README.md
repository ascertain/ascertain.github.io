# ascertain.github.io

Personal engineering blog by Mohammad Kashif.

**Topics:** Test Automation, Playwright, CI/CD, Agentic AI Workflows, DevOps, Quality Engineering

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:4000`

## Writing a New Post

Add a Markdown file to `_posts/` with the naming convention:

```
_posts/YYYY-MM-DD-title-slug.md
```

## Deploy

Push to `main` branch — GitHub Pages builds and deploys automatically.
